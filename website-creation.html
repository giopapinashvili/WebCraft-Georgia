რა შედის

ფასში შემავალი სამუშაო — გასაგებად, პუნქტებად. რაც სიაში არაა, ბრიფზე ვთანხმდებით ცალკე.

  • სტრუქტურა და ტექსტების განლაგება — რომელი ინფორმაცია რომელ გვერდზე და რა თანმიმდევრობით
  • დიზაინი შენს ბრენდზე — ფერები, შრიფტები და ვიზუალი ლოგოს მიხედვით
  • 4-8 გვერდი — მთავარი, სერვისები, ჩვენ შესახებ, გალერეა, კონტაქტი და ქვეგვერდები
  • CMS — კონტენტის მართვა — ტექსტს და ფოტოს თავად ცვლი, ინსტრუქციით
  • მობილური, ტაბლეტი, დესკტოპი — სამივეზე ცალკე შემოწმებული, არა „ავტომატურად მოერგება“
  • საკონტაქტო ფორმა — შევსება პირდაპირ საიტიდან, WhatsApp-ის დუბლირებით
  • ბაზისური SEO — title, description, sitemap.xml, robots.txt, Schema markup
  • Google Search Console + Analytics — დაყენებული და შენს ანგარიშზე მიბმული
  • გაშვება — დომენი, ჰოსტინგი, SSL სერტიფიკატი და წვდომების გადმოცემა
  • 2 რაუნდი შენიშვნა — უფასოდ, გაშვების შემდეგაც

არ იცი, რომელი პაკეტი გჭირდება?

დაგვირეკე ან მოგვწერე — 20 წუთში გავარკვევთ, რა არის შენს შემთხვევაში საჭირო და რა არის ზედმეტი ხარჯი.

02

როგორ არის აწყობილი

ტექნიკური მხარე, რომელიც კლიენტს არ უჩანს, მაგრამ შედეგზე ყველაზე მეტად მოქმედებს.

01

ხელით დაწერილი კოდი

სუფთა HTML, CSS და JavaScript. არანაირი გადატვირთული კონსტრუქტორი, რომელიც 40 ზედმეტ სკრიპტს ჩატვირთავს. საიტი მსუბუქია და სწრაფად იხსნება 3G-ზეც.

02

Core Web Vitals

LCP, CLS და INP — Google-ის სამი მეტრიკა, რომელიც რანჟირებაზე მოქმედებს. სურათები WebP-ში, შრიფტები preload-ით, ლეიაუტი არ ხტება ჩატვირთვისას.

03

სემანტიკური HTML

სათაურების სწორი იერარქია, landmark-ები, alt ტექსტები. ეს ერთდროულად SEO-ცაა და ხელმისაწვდომობაც — საიტს კითხულობს screen reader-იც.

04

კონტენტის მართვა

გაჩვენებთ როგორ შეცვალო ტექსტი და ფოტო. თუ არ გინდა თავად — მუდმივი მხარდაჭერის პაკეტში ეს ჩვენი საქმეა.

05

უსაფრთხოება

HTTPS ნაგულისხმევად, ფორმაზე spam-დაცვა, არანაირი ღია ადმინ პანელი, რომელსაც ბოტები ესხმიან თავს.

06

სიჩქარის ჰოსტინგი

Cloudflare Pages — გლობალური CDN, უფასო SSL და პრაქტიკულად ნულოვანი downtime. მცირე საიტისთვის ჰოსტინგის ხარჯი 0₾-ია.

03

ვისთვის არის

თუ ერთ-ერთი პუნქტი შენზეა — ეს სერვისი შენთვისაა.

  • გაქვს მცირე ბიზნესი ან სერვისი და კლიენტები ჯერჯერობით მხოლოდ ინსტაგრამიდან მოდიან
  • საიტი საერთოდ არ გაქვს, მაგრამ პარტნიორები ან კლიენტები ითხოვენ
  • გინდა ერთ ბმულში მოთავსდეს სერვისები, ფასები, გალერეა და კონტაქტი
  • გჭირდება ოფიციალური სახე — ტენდერისთვის, ბანკისთვის ან საერთაშორისო პარტნიორისთვის
  • მოგბეზრდა ერთი და იგივე კითხვებზე პასუხი Messenger-ში დღეში 20-ჯერ

04

კითხვები ამ სერვისზე

დანარჩენ კითხვებზე პასუხი მთავარ გვერდზეა — ან უბრალოდ მოგვწერე.

რატომ ჯდება ნაკლები, ვიდრე სააგენტოში?

პროცესის რუტინული ნაწილი — კომპონენტების აწყობა, responsive ტესტირება, სურათების ოპტიმიზაცია, meta ტეგები — ხელოვნური ინტელექტით არის აჩქარებული. ის, რაზეც ადრე კვირა იხარჯებოდა, ახლა დღეებში კეთდება.

დიზაინსა და გადაწყვეტილებებს ადამიანი იღებს, კოდი კი ხელით მოწმდება. ამას ემატება ის, რომ ოფისისა და შუამავლების ხარჯი არ გვაქვს — შენ იხდი სამუშაოში, არა ბიუროკრატიაში.

რა შედის პირველი წლის ფასში?

დომენი (.ge ან .com), ჰოსტინგი, SSL სერტიფიკატი და ტექნიკური მხარდაჭერა — 12 თვე საჩუქრად, დამატებითი გადასახადის გარეშე.

მე-2 წლიდან განახლება: 49₾/თვე ლენდინგისთვის და 99₾/თვე ბიზნეს საიტისა და მაღაზიისთვის. გაუქმება ნებისმიერ დროს, ჯარიმის გარეშე.

ტექსტები ვინ უნდა დაწეროს?

შენ იცი შენი ბიზნესი — ტექსტების ძირითადი შინაარსი შენგან მოდის. ჩვენ ვასწორებთ სტრუქტურას, სათაურებს და ვაწყობთ ისე, რომ იკითხებოდეს.

თუ დროც არ გაქვს და სურვილიც — ტექსტების დაწერა ცალკე შეთანხმებაა და ვადას +2-3 დღეს ამატებს.

რამდენი გვერდი მჭირდება?

უმეტეს მცირე ბიზნესს 4-5 გვერდი ჰყოფნის: მთავარი, სერვისები, ჩვენ შესახებ, გალერეა, კონტაქტი. ბრიფზე ვნახავთ, რა აქვს აზრი შენს შემთხვევაში — ცარიელი გვერდები საიტს არ აძლიერებს.

თუ მოგვიანებით გვერდის დამატება მოვინდომე?

ერთი დამატებითი გვერდი — 80-120₾, არსებული დიზაინის ფარგლებში. მუდმივი მხარდაჭერის პაკეტში მცირე დამატებები ისედაც შედის.

სხვა ენაზე ვერსია შესაძლებელია?

დიახ. მეორე ენა (ინგლისური ან რუსული) სრული საიტისთვის +40% ღირს, რადგან ორივე ვერსია ცალკე უნდა აეწყოს და hreflang ტეგებით დაუკავშირდეს ერთმანეთს.
